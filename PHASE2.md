# Phase 2: foundation and design system

Copy `lib/`, `test/` and `tools/` over your project (this replaces the counter demo),
then from the project root:

    bash tools/setup_phase2.sh      # adds flutter_riverpod + go_router, analyzes, tests
    flutter run

Sign in with a demo role on the first screen; "Design system gallery" shows every shared widget.

Not yet verified by a compiler (no Flutter SDK was available when this was written).
Paste any `flutter analyze` / `flutter test` output back and it will be fixed.
